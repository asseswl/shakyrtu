ПОДКЛЮЧЕНИЕ GOOGLE ТАБЛИЦЫ

1. Создай новую Google Таблицу.
2. В ней открой: Расширения → Apps Script.
3. Удали код по умолчанию.
4. Открой файл google-apps-script.gs из этого архива и скопируй весь код в Apps Script.
5. Сохрани проект.
6. Нажми Развернуть (Deploy) → Новое развертывание (New deployment).
7. Тип: Веб-приложение (Web app).
8. Выполнять от имени: Я (Me).
9. У кого есть доступ: Все (Anyone).
10. Нажми Deploy и скопируй URL веб-приложения.
11. Открой script.js из сайта.
12. Найди:
    googleSheetsUrl: ""
13. Вставь URL между кавычками.
14. Загрузи обновленный script.js на GitHub.

После этого каждый ответ будет автоматически записываться на лист «Ответы».
